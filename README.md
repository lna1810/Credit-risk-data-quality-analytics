# Credit Risk & Data Quality Analytics Platform

## Overview

An end-to-end data analytics project focused on credit risk analysis, loan default patterns, and data quality assessment.

The project transforms raw credit data into validated insights using Python, SQL, Machine Learning, Power BI, and Excel.

## Objectives

- Analyze credit risk and loan default patterns
- Clean and validate credit data
- Perform SQL-based risk analysis
- Build machine learning models for default prediction
- Develop interactive Power BI dashboards
- Implement a data quality and controls framework
- Create a reproducible analytics workflow

## Tools & Technologies

- Python — Pandas, NumPy, Matplotlib, Seaborn
- SQL — DuckDB
- Machine Learning — Scikit-learn, SHAP
- Power BI — Interactive dashboards
- Excel — Data quality reporting
- GitHub — Version control and documentation

## Dataset

- **32,581 loan records**
- **12 variables**
- Target variable: `loan_status`
- Includes borrower, loan, income, interest-rate, loan-grade and credit-history information

## Project Workflow

**Raw Data → Python Cleaning → Data Quality → EDA → SQL Analysis → Risk Analysis → Machine Learning → Power BI**

## Power BI Dashboard

The dashboard contains three pages:

1. **Executive Risk Overview**
2. **Credit Risk Analytics**
3. **Data Quality & Controls**

## Key Outcomes

- Identified patterns associated with loan defaults
- Performed structured credit-risk analysis
- Developed Logistic Regression and Random Forest models
- Evaluated model performance using classification metrics
- Created an interactive three-page Power BI dashboard
- Established a data-quality assessment framework
